# new鱼排宠物助手

摸鱼派（fishpi.cn / new.fishpi.cn）宠物系统的自动助手油猴脚本：自动照顾、自动安排活动并领奖、自动休息、精力不足先喝咖啡、乱斗闯关与武器强化。作者：Mairo（v1.2.0）

## 安装

1. 浏览器安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)
2. 新建脚本，把 `fishpi-auto-pet.user.js` 的内容粘贴进去保存
   （或直接把 `.user.js` 文件拖进浏览器，按提示安装）
3. 打开 https://new.fishpi.cn/pets 并**登录**，页面右下角出现 🐾 悬浮按钮即启动成功

## 使用

- 点击 🐾 按钮打开面板（设置/状态/日志三个 Tab），或用油猴菜单
- 🐾 上的**绿点** = 助手已启用
- 面板「状态」Tab 实时显示：宠物属性条（饥饿/口渴/心情/精力/友谊）、当前活动与倒计时、安排计划
- 日志会记录每次自动操作与领奖结果

## 功能一览

| 功能 | 说明 |
|---|---|
| 自动照顾 | 饥饿/口渴/心情低于阈值 → 喂食/浇水/玩耍（每轮只做一件，少触发风控） |
| 自动安排活动 + 领奖 | 空闲时按策略开活动（兼职/外出/学校），到点自动领奖 |
| 自动休息 | 精力低于阈值自动休息，到点自动叫醒（精力够了可提前叫醒） |
| ☕ 自动咖啡（v1.2.0） | 精力不足先买咖啡：**64 积分 → +30 精力，立刻生效**，每天限 3 杯；喝不到（次数用完/积分不够/有活动在身）才回退到休息——比睡 4 小时划算 |
| ⚔️ 乱斗自动化（v1.1.0） | 宠物 Lv.10 解锁：每日闯关 3 场拿材料（胜败均可领 5/5/10），材料够就强化出战武器 |
| 每日补给 / 小铺补货 | 自动领每日补给；口粮低于阈值自动买回 |
| 故事奖励 / 自动合成 | 材料够就领故事奖励、自动合成 |
| 风控保护 | 触发人机验证自动暂停，手动过验证后点「启用」继续 |

## 工作原理

```
每轮检查（默认 10s 一次）：
  1. 风控检查 GET /api/v3/me/pet/risk
     → 需要人机验证 → 自动暂停 + 提示，等你手动过滑块后点「启用」继续
  2. 拉取宠物状态 GET /api/v3/me/pet
  3. 有活动进行中 → 到点自动领奖 POST /api/v3/me/pet/activities/claim
     休息中 → 到点自动叫醒（精力够可提前叫醒）
  4. 乱斗（Lv.10+）：每日闯关打满 3 场拿材料 → 材料够就强化武器
  5. 自动照顾：饥饿/口渴/心情低于阈值 → feed / water / play
  6. 精力太低 → 先试咖啡（64 积分 → +30 精力，立刻生效）
     咖啡喝不到 → 安排休息（restDurationMs 服务端规则），醒来继续
  7. 空闲且精力足够 → 按策略安排活动：兼职 / 外出 / 学校
  8. 全部不可行 → 待机，面板说明原因
```

所有写操作都带 `Idempotency-Key`，HTTP 层与「new鱼排红包」一致：页面原生 fetch 优先 + 250ms 串行节流 + 401 自动刷新 token + 429 退避。登录态失效时会自动同步官方 token（日志显示「已同步官方 token」）。

## 乱斗说明（v1.1.0+）

- **解锁条件**：宠物等级 Lv.10
- **每日闯关**：自动打 3 场（`POST /api/v3/me/pet/brawl/matches`），**胜败都发材料**，每日奖励 5 / 5 / 10
- **武器强化**：材料够就强化（`POST /api/v3/me/pet/brawl/upgrade`）。版本 2 起所有武器共用强化曲线，**选强化等级最高的武器即最优**，脚本自动选
- 战斗结果、材料收支都写入日志

## 咖啡说明（v1.2.0+）

- **入口**：精力低于休息阈值时先走咖啡，不再直接睡
- **代价/收益**：64 积分 → +30 精力（上限 100），立刻生效，每天限 3 杯
- **限制**（与官方 UI 一致）：宠物必须空闲（无活动/休息在身）、精力未满、积分足够、当日次数未用完
- **回退**：次数用完 → 半小时后再查（跨天自动恢复）；积分不够 → 半小时后再查；有活动在身 → 本轮跳过；购买失败 → 10 分钟冷却
- 关闭方法：设置页取消勾选「精力不足先喝咖啡」

## 风控与自查

- 每轮只做一个写操作、请求 250ms 串行节流——对齐官方前端节奏，尽量不惊动风控
- 人机验证触发频率为零（观测中）；一旦触发：自动暂停 → 你手动过验证 → 点「启用」继续
- 登录态失效（401）自动刷新 token 并继续；日志出现「已同步官方 token」即恢复正常
- 是否使用自动助手请遵守社区用户协议，风险自担

## 故障排查

| 现象 | 处理 |
|---|---|
| 无悬浮按钮 | 确认 Tampermonkey 已启用本脚本，`@match` 覆盖当前站点，且已在 fishpi.cn 登录 |
| 日志出现 401/登录失效 | 脚本会自动刷新 token；持续出现则重新登录并刷新页面 |
| 一直显示「待机」 | 看面板说明的原因：通常是精力不足、活动冷却中或资源不够 |
| 咖啡没触发（今天 remaining 0） | 正常：每日 3 杯用完会安静回退到休息，跨天自动恢复 |
| 乱斗一直没打 | 确认宠物已到 Lv.10，且「乱斗」两个开关已勾选 |
| 触发人机验证被暂停 | 手动过一次滑块，然后点面板「启用」 |
